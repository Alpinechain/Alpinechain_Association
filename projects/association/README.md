# Projet Association AlpineChain

## Finalité

Piloter la gouvernance, les adhésions, les partenariats transversaux, l’administration et le développement de l’association AlpineChain.

## Périmètre

- bureau et décisions associatives ;
- adhésions et membres ;
- partenariats généraux ;
- administration et obligations légales ;
- coordination entre Meetup Bitcoin, Souveraineté 3.0 et B-Only ;
- stratégie et feuille de route associative.

## Sources de vérité

| Sujet | Outil |

## Emplacements Nextcloud

| Usage | Chemin réel |
|---|---|
| Administration générale | `Administration/` |
| Adhérents et acteurs | `Administration/Acteurs/` |
| Comptabilité et pièces | `Administration/Comptabilité/` |
| AG, statuts et règlements | `Administration/PV AG Statut Réglement/` |
| Comptes rendus annuels | `Compte-rendus/<année>/` |
| Logos et charte | `LOGO Alpinechain/` |
| Contrats transversaux | `Administration/Contrats-Conventions/` à créer |

Les dossiers `Acteurs/Adhérents`, `Comptabilité` et les documents bancaires sont privés. Ils ne doivent pas être inclus dans un partage public global.

## Règles

- Une décision engageant l’association doit être validée par la personne ou l’instance compétente.
- Les données personnelles ne sont pas copiées inutilement dans GitHub.
- Les actions concrètes sont suivies dans les Issues avec le label `project:association`.
- Les droits Nextcloud sont accordés par dossier selon le besoin réel.
- L’incident de partage public est suivi dans [#37](https://github.com/Alpinechain/Alpinechain_Association/issues/37).
