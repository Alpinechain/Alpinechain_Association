# Prompt ChatGPT Work — kit partenaire B-Only’26

**État :** `PRÊT À RELIRE`.

Instruction attendue :

> Prépare le kit de diffusion pour {{PARTENAIRE}}.

Avant de rédiger, lire les informations validées dans GitHub. Produire :

- un message personnalisé ;
- les textes sociaux utiles ;
- un texte newsletter ;
- un brief visuel ;
- un brief HeyGen seulement s’il est demandé ;
- la liste des fichiers ou assets nécessaires.

Ne jamais inventer une relation, un statut 2026, une présence, une date, un
logo, un témoignage ou une publication. Signaler les contradictions et laisser
le livrable `PRÊT À RELIRE`. Pour les visiteurs 2025, traiter uniquement le
segment agrégé sans recopier de données personnelles dans GitHub.

Le ton par défaut est personnel, amical et complice. Tutoyer, écrire avec « on »
et donner l’impression d’un message réellement adressé à une connaissance de
l’écosystème Bitcoin. Éviter le vocabulaire institutionnel et publicitaire. Le
vouvoiement reste possible si la relation documentée l’exige.

## Données d’entrée minimales

```text
PARTENAIRE={{nom public ou attendee-2025}}
SEGMENT={{activation_segment}}
RELATION_BONLY={{relation validée}}
TON={{preferred_tone}}
LOGO={{source validée ou aucun}}
CTA=https://b-only.org/
```

Si une donnée manque, la placer dans « Points à valider » au lieu de la
compléter par déduction. Respecter la phrase « Il n’y a évidemment aucune
obligation de publication. » dans chaque message d’approche.

## Sortie attendue

1. message personnalisé de 120 à 180 mots ;
2. textes pour les seuls réseaux utiles, avec X limité à 240 caractères ;
3. newsletter courte et développée ;
4. brief des formats visuels nécessaires ;
5. brief HeyGen uniquement sur demande ;
6. liste des sources, assets manquants et validations nécessaires.
