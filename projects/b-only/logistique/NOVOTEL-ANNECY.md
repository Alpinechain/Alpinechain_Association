# Novotel Annecy Centre — références salles B-Only 2026

Dernière mise à jour : 2026-09-21

## Rôle

Centraliser les références communes utilisées pour préparer l’implantation physique de B-Only 2026 au Novotel Annecy Centre.

Ce fichier ne remplace pas les plans de sécurité ni les dimensions validées par le Novotel. Les implantations finales restent suivies dans l’Issue logistique #25.

- Fichier reçu : `Novotel-Annecy-Centre-MICE.pdf`

- La brochure est déjà référencée dans le registre des organisations comme disponible dans Nextcloud sous `02_Sponsors-Contrats/Novotel/`.

- **Le Podium** : amphithéâtre / salle principale de conférence de **150 m²**, capacité théâtre annoncée **130 personnes**.

### Plan PowerPoint de travail

- Fichier reçu et modifié par Cédric le 21 septembre 2026 : `B-Only_2026_plan_salle_Novotel_editable(2).pptx`
- Usage : base de travail éditable pour répartir les tables / stands.
- Le plan représente **2 salles sur les 3** de l’ensemble Altitude + Dénivelé + Adrénaline.
- Les objets tables copiés depuis la slide 1 utilisent la référence de travail **1,50 m × 0,75 m** et sont à la même échelle que le plan PowerPoint.

Le fichier PowerPoint source est un document de production lourd : GitHub suit sa référence, son statut et les décisions ; la copie de travail pérenne doit être conservée dans Nextcloud avec les autres documents de production/logistique.
