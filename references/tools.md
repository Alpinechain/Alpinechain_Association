# Référentiel des outils AlpineChain

## Rôle

Ce document indique la fonction de chaque outil et sa source de vérité. Il ne contient aucun mot de passe, token, clé API ou donnée personnelle sensible.

| Outil | Fonction principale | Source de vérité pour | Hébergement / contrôle |
|---|---|---|---|
| ChatGPT | Analyse, coordination, rédaction et revue | Travail préparatoire, jamais décision finale isolée | OpenAI, projets AlpineChain |
| GitHub `Alpinechain_Association` | Pilotage et mémoire opérationnelle | Issues, décisions, procédures, priorités | Organisation Alpinechain |
| GitHub `Serveur` | Infrastructure as code et runbooks | Configuration, exploitation et reprise serveur | Organisation Alpinechain |
| GitHub Projects | Vue de portefeuille | Statuts, responsables, échéances et priorités | À créer / administrer dans GitHub |
| Nextcloud | Fichiers et collaboration | Documents, contrats, visuels, photos et supports | Serveur AlpineChain |
| Pretix | Billetterie | Événements, commandes, billets et participants | Serveur AlpineChain |
| Paheko | Comptabilité associative | Écritures, pièces et suivi comptable | Serveur AlpineChain |
| Dolibarr | CRM / ERP | Contacts entreprises, sponsors, devis et factures | Serveur AlpineChain |
| PeerTube | Publication vidéo | Vidéos publiques et playlists | Serveur AlpineChain |
| be-BOP | Site, boutique ou caisse selon usage | Données opérationnelles de la plateforme | Serveur AlpineChain |
| be-BOP Bar | Commandes du bar B-Only | Produits et commandes bar | Serveur AlpineChain |
| Infomaniak | Domaine, DNS, site et messagerie | Hébergement public et courriels | Compte AlpineChain |
| Meetup.com | Découverte locale | Présentation publique et inscriptions selon événement | Compte AlpineChain |
| LinkedIn | Réseau professionnel | Diffusion uniquement | Compte / page AlpineChain |
| X | Communauté Bitcoin et annonces courtes | Diffusion uniquement | Compte AlpineChain |
| Facebook | Relais local | Diffusion uniquement | Meta Business Suite |
| Instagram | Visuels, rappels et stories | Diffusion uniquement | Meta Business Suite |
| Nostr | Diffusion souveraine | Diffusion uniquement | Clés et relais sous contrôle AlpineChain |

## Règles

1. GitHub suit les actions et décisions ; Nextcloud conserve les fichiers lourds.
2. Les outils métiers restent la source de vérité de leurs données propres.
3. Les réseaux sociaux ne servent jamais d’archive principale.
4. Les secrets sont stockés dans un gestionnaire de mots de passe partagé, jamais dans ce dépôt.
5. Toute intégration automatisée doit disposer d’un responsable humain et d’une procédure de révocation.
