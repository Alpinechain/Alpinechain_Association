## Convention de liaison

Chaque dossier projet GitHub doit pointer vers son dossier Nextcloud permanent. Chaque dossier Nextcloud actif devrait contenir un fichier `LISEZ-MOI.txt` avec le lien vers le projet ou l’Issue GitHub correspondante.

## Points à vérifier

- Le lien partagé actuel est-il le dossier racine permanent ou un partage temporaire ?
- Les droits sont-ils limités aux personnes nécessaires ?
- Une corbeille, une rétention et une sauvegarde externe sont-elles configurées ?
- L’arborescence cible existe-t-elle réellement ou doit-elle être créée ?

Aucun de ces points n’est considéré comme validé tant qu’il n’a pas été vérifié dans Nextcloud.
