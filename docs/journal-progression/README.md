# Journal de progression AlpineChain Association

Version : V0.1  
Dernière mise à jour : 2026-05-12

---

## 1. Rôle du journal

Ce dossier sert à suivre la progression réelle du système AlpineChain Association.

Il documente :

- les fichiers créés ;
- les décisions structurantes ;
- les points encore flous ;
- les améliorations à prévoir ;
- les prochaines actions.

Ce journal ne remplace pas les notes hebdomadaires ou mensuelles. Il sert de fil conducteur global.

---

## 2. Format recommandé

Créer une entrée par semaine quand le projet avance réellement :

```text
docs/journal-progression/YYYY-WXX.md
```

Exemple :

```text
docs/journal-progression/2026-W20.md
```

---

## 3. Modèle d’entrée hebdomadaire

```markdown
# Journal de progression — YYYY-WXX

## 1. Résumé

Résumé court de la semaine.

## 2. Fichiers créés ou modifiés

- `fichier.md` : rôle du fichier.

## 3. Décisions prises

- Décision 001 : résumé.

## 4. Points ouverts

- Point à clarifier.

## 5. Prochaine action unique

- Action courte, vérifiable et utile.
```

---

## 4. Règles

- Ne pas créer d’entrée vide.
- Ne pas transformer le journal en compte-rendu fleuve.
- Noter seulement ce qui aide à piloter le projet.
- Une entrée doit finir par une prochaine action unique.
