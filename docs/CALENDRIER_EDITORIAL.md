# Calendrier éditorial AlpineChain

Version : V0.1  
Dernière mise à jour : 2026-05-12

---

## 1. Rôle du document

Ce document sert à piloter les publications liées aux rendez-vous AlpineChain.

Il ne remplace pas le calendrier réel des événements. Il sert à structurer la production de contenus avant et après chaque rendez-vous.

---

## 2. Formats suivis

| Format | Rythme | Objectif éditorial |
|---|---:|---|
| Atelier Bitcoin | Premier mercredi du mois | Annoncer, expliquer, convertir, capitaliser |
| Souveraineté 3.0 | Troisième jeudi du mois | Poser une question, ouvrir le débat, connecter |
| Beer2Beer | Selon calendrier | Maintenir le lien communautaire |
| Micro-projets | Au cas par cas | Tester une idée locale |

B-Only est hors périmètre de ce document et devra avoir son propre système.

---

## 3. Séquence type par événement

### J-21 — Cadrage

- thème ;
- public cible ;
- promesse ;
- angle principal ;
- CTA ;
- lien d’inscription ;
- ressources utiles ;
- visuel à produire.

### J-14 — Publication principale

- article blog ou page événement ;
- description Meetup ;
- texte Pretix si nécessaire ;
- annonce LinkedIn ;
- annonce X ;
- annonce Facebook ;
- annonce Instagram ;
- visuel principal.

### J-7 — Relance pédagogique

- un point de contexte ;
- un bénéfice concret ;
- une question simple ;
- rappel du CTA.

### J-3 — Relance pratique

- date ;
- horaire ;
- lieu ;
- niveau requis ;
- matériel à prévoir ;
- lien d’inscription.

### J-1 — Dernier rappel

- message court ;
- promesse claire ;
- CTA direct.

### J+1 / J+3 — Capitalisation

- compte-rendu ;
- questions posées ;
- ressources partagées ;
- photos ou supports ;
- retours qualitatifs ;
- prochaine date.

## 5. Règles éditoriales rapides

Avant publication, vérifier :

```text
[ ] Date correcte
[ ] Horaire correct
[ ] Lieu correct
[ ] Lien d’inscription correct
[ ] CTA clair
[ ] Public cible compréhensible
[ ] Niveau technique adapté
[ ] Ton cohérent AlpineChain
[ ] Validation humaine faite
```
