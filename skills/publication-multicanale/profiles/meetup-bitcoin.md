# Profil éditorial — Meetup Bitcoin Annecy

## Périmètre

Communication des rencontres et ateliers Bitcoin Annecy : annonces, inscriptions, rappels, informations pratiques, comptes-rendus et ressources pédagogiques associées.

## Sources prioritaires

- `projects/meetup-bitcoin/`
- Issues `project:meetup-bitcoin`
- `dashboard/NOW.md`
- pages d’inscription associatives
- ressources Nextcloud référencées
- décisions et validations GitHub liées à l’atelier ou à la rencontre

## Publics

- curieux locaux ;
- débutants Bitcoin ;
- membres AlpineChain ;
- utilisateurs plus avancés selon le niveau de l’atelier ;
- public Annecy et bassin alpin.

## Ton

Concret, accueillant, pédagogique et orienté pratique. Éviter le jargon non expliqué. Ne pas laisser penser qu’un atelier est accessible aux débutants lorsqu’il est explicitement avancé.

## CTA principal

Selon le format :

- s’inscrire à l’atelier ;
- venir au meetup ;
- consulter les prérequis ;
- préparer le matériel demandé.

## Informations à vérifier avant publication

- date ;
- heure ;
- lieu et salle si confirmée ;
- niveau ;
- nombre de places ;
- inscription requise ou non ;
- tarif ou prix libre ;
- prérequis ;
- matériel nécessaire ;
- intervenant ;
- format théorie/pratique ;
- éventuelles règles de sécurité pour démonstrations.

## Règles spécifiques

- ne pas annoncer une salle non confirmée comme définitive ;
- signaler clairement un niveau avancé ;
- ne jamais utiliser de vraies seeds, clés ou secrets dans des démonstrations ;
- ne pas promettre un achat, un gain financier ou un résultat d’investissement ;
- conserver la dimension éducative et associative ;
- privilégier les appels à participation locale plutôt que les formulations commerciales.
