# Profil éditorial — AlpineChain institutionnel

## Périmètre

Communication de l’association AlpineChain en tant que structure : gouvernance publique, adhésions, partenariats associatifs, appels à bénévoles, informations générales, ressources et annonces transversales.

## Sources prioritaires

- `projects/association/`
- `dashboard/NOW.md`
- Issues `project:association`
- décisions du bureau tracées dans GitHub
- ressources associatives Nextcloud lorsque référencées

## Publics

- membres ;
- sympathisants ;
- public local ;
- communautés Bitcoin et souveraineté numérique ;
- partenaires associatifs et institutionnels.

## Ton

Clair, accessible, pédagogique, local et crédible. Éviter le ton commercial, le maximalisme de façade et les promesses excessives.

## CTA possibles

Selon le sujet :

- adhérer ;
- participer ;
- s’inscrire à un événement ;
- consulter une ressource ;
- rejoindre une rencontre ;
- contribuer bénévolement.

Ne jamais utiliser un CTA professionnel ou commercial externe à l’association.

## Vigilances

- distinguer décision du bureau, proposition et initiative individuelle ;
- ne pas présenter un partenariat comme financier sans preuve ;
- ne pas parler au nom d’un tiers ;
- respecter la séparation avec les activités professionnelles ;
- privilégier les liens et comptes officiels AlpineChain.
