# Prompt — Cadrage événement AlpineChain

Version : V0.1  
Dernière mise à jour : 2026-05-12

---

## Rôle du prompt

Ce prompt sert à cadrer un événement AlpineChain avant toute production de contenu.

Il doit être utilisé avant de demander :

- un article ;
- une annonce Meetup ;
- des posts réseaux sociaux ;
- un visuel ;
- un compte-rendu ;
- une séquence de relance.

---

## Prompt à copier-coller

```text
Projet : AlpineChain Association
Rôle attendu : agent coordinateur + analyste éditorial

Objectif : cadrer un événement AlpineChain avant production de contenu.

Type d’événement : [Atelier Bitcoin / Souveraineté 3.0 / Beer2Beer / Micro-projet]
Date : [date]
Horaire : [horaire]
Lieu : [lieu]
Lien d’inscription : [lien]
Thème : [thème]
Public cible : [public]
Niveau requis : [débutant / intermédiaire / avancé / ouvert à tous]
Format : [atelier pratique / discussion / table ronde / démonstration / autre]
Intervenants : [noms si connus]
Contexte utile : [éléments déjà validés]
Contraintes : [ton, durée, éléments à éviter, ressources obligatoires]

Avant de produire quoi que ce soit :
1. reformule l’objectif de l’événement ;
2. identifie la promesse publique ;
3. propose un angle principal ;
4. liste les ambiguïtés ou informations manquantes ;
5. propose les livrables nécessaires ;
6. propose une séquence J-14 / J-7 / J-3 / J-1 / J+1 ;
7. vérifie que le contenu reste cohérent avec AlpineChain : Bitcoin, souveraineté numérique, pédagogie, local, non spéculatif.

Sortie attendue :
- cadrage synthétique ;
- angle éditorial ;
- messages clés ;
- CTA ;
- livrables recommandés ;
- points à valider humainement.
```

---

## Definition of Done

Le cadrage est terminé quand :

```text
[ ] le type d’événement est clair ;
[ ] le public cible est défini ;
[ ] la promesse publique est formulée ;
[ ] le CTA est identifié ;
[ ] les informations manquantes sont listées ;
[ ] les livrables à produire sont connus ;
[ ] la validation humaine reste prévue avant publication.
```
